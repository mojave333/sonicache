# Синхронизация с плеером и телефоном: часть 3 — iPhone и Android по Wi-Fi

Дата: 2026-10-14. Продолжает [часть 1](2026-10-14-device-sync-design.md) и
[часть 2](2026-10-14-device-sync-mtp-design.md). Пользователь попросил делать без согласований;
решения ниже приняты по ходу и перечислены в отчёте.

## Зачем

iPhone не даёт программе на компьютере доступа к своим файлам: ни как диск, ни по MTP. Android без
кабеля тоже недоступен. Чтобы музыка из Sonicache попала на телефон, программа раздаёт библиотеку по
домашней сети так, как это понимают готовые плееры, а плеер на телефоне слушает её и скачивает
выбранное для прослушивания без сети.

## Выбор протокола

**Subsonic API** (1.16.1, с пометкой OpenSubsonic) — общий язык домашних музыкальных серверов
(Navidrome, Airsonic, Gonic). Его понимают бесплатные плееры с офлайн-загрузкой:

- iPhone: **Amperfy** (бесплатный, открытый код), play:Sub, substreamer;
- Android: **Ultrasonic** (бесплатный, открытый код), Symfonium, Tempo.

WebDAV отвергнут: на iPhone его понимают только файловые менеджеры и немногие плееры, без обложек,
тегов и плейлистов. DLNA отвергнут: без офлайн-загрузки на iPhone.

## Что делает программа

- По переключателю открывает сервер Subsonic на порту 4533 (как у Navidrome; занят — следующий
  свободный) на всех сетевых адресах компьютера. По умолчанию выключен.
- Отдаёт всю библиотеку: исполнителей, альбомы, треки с тегами, обложки, плейлисты (свои, «Недавно
  слушали», «Часто слушаю»), избранное. **Что держать на телефоне без сети, выбирают в плеере** — выбор
  по устройствам из части 1 здесь не нужен.
- Звёздочка на альбоме в плеере ставит или снимает его в «Избранном» Sonicache; прослушанное на
  телефоне идёт в счётчик прослушиваний (и в «Часто слушаю»).
- Плееру, который просит mp3 (`format=mp3`; так Amperfy и другие обходят opus, который iPhone не
  играет), файл отдаётся пережатым на лету через ffmpeg; иначе — как есть, с перемоткой (`Range`).

## Безопасность

- Каждый запрос — с логином и паролем: `p=` открытым текстом или `enc:`, либо токен
  `t=md5(пароль+s)` с солью `s`. Неверные — ошибка 40. Сравнение — без утечки по времени.
- Логин `sonicache`, пароль — 10 случайных строчных букв и цифр без похожих (`l`, `1`, `o`, `0`), чтобы
  его было легко набрать на телефоне; кнопка «Новый пароль». Пароль хранится открытым текстом в
  `wifi.json` в папке данных программы: токен Subsonic требует, чтобы сервер знал пароль.
- Файлы отдаются только по id из списка библиотеки: путей в запросах нет, выйти за папки библиотеки
  нельзя.
- Настройки сервера — в отдельном `wifi.json`, а не в общих настройках: окно сохраняет их целиком из
  своей копии и затёрло бы пароль, сменённый программой.

## Архитектура

### `sonicache/subsonic.py`

Модуль программы (не движка: ему нужны библиотека, плейлисты и избранное из `gui`). Без зависимостей
от `gui` — всё приходит через `Source`:

| `Source` (передаёт `gui`) | что это |
|---|---|
| `library() -> (items, tracks)` | записи библиотеки (как `Api.library`) и треки с тегами (как `Api.tracks`) |
| `playlists() -> list[{id, name, tracks}]` | свои и «умные» плейлисты |
| `favourites() -> list[str]`, `set_favourite(path, on)` | избранные альбомы |
| `cover(path) -> bytes or None` | обложка записи или файла |
| `listened(track)` | прослушанный трек |
| `ffmpeg() -> str or None` | для пережатия |

- **`Index`** — снимок библиотеки для ответов: исполнители, альбомы, песни, плейлисты, жанры по id.
  id стабильные: `ar-`, `al-`, `tr-`, `pl-` и 12 знаков sha1 пути (или ключа). Строится по первому
  запросу и живёт 60 секунд; `startScan` строит заново.
- **`Api(source, credentials)`** — `handle(path, params, headers) -> Response`: чистая функция над
  запросом, без сокетов (так её и тестируем). Ответы в XML по умолчанию и в JSON при `f=json`.
- **`Listener`** — `ThreadingHTTPServer` в фоне: GET, POST (форма) и HEAD на `/rest/<метод>[.view]`.

### Методы Subsonic

`ping`, `getLicense`, `getUser`, `getOpenSubsonicExtensions` (`formPost`), `getMusicFolders`,
`getIndexes`, `getMusicDirectory`, `getArtists`, `getArtist`, `getAlbum`, `getSong`, `getAlbumList`,
`getAlbumList2` (`newest`, `recent`, `frequent`, `random`, `alphabeticalByName`,
`alphabeticalByArtist`, `starred`, `byYear`, `byGenre`), `getRandomSongs`, `getGenres`,
`getSongsByGenre`, `search2`, `search3`, `getPlaylists`, `getPlaylist`, `getStarred`, `getStarred2`,
`star`, `unstar`, `scrobble`, `stream`, `download`, `getCoverArt`, `getScanStatus`, `startScan`.
Пустые ответы для того, чего у программы нет: `getNowPlaying`, `getPodcasts`,
`getInternetRadioStations`, `getBookmarks`, `getPlayQueue`, `savePlayQueue`, `getShares`. Прочее —
ошибка 0 «не поддерживается». Неизвестный id — ошибка 70.

### Окно и `gui.py`

- `Api.wifi()` — `{on, running, port, addresses, user, password, error}`; `set_wifi(on)`,
  `new_wifi_password()`. Сервер поднимается при старте программы, если был включён.
- Адреса — IPv4 компьютера в локальной сети (`192.168.*`, `10.*`, `172.16–31.*`), первым — тот, через
  который идёт трафик наружу.
- В разделе «Устройства» библиотеки — постоянная строка «Телефон по Wi-Fi» (иконка `i-link`). Её
  страница: переключатель «Открыть библиотеку по Wi-Fi»; адрес, логин, пароль с кнопками
  «Скопировать» и «Новый пароль»; как подключить: какое приложение поставить на iPhone и на
  Android, «Добавить сервер Subsonic»; что телефон и компьютер должны быть в одной сети, программа —
  открыта (можно свернуть в область уведомлений), а на вопрос брандмауэра Windows при первом
  включении нужно разрешить частные сети.

## Ошибки

- Порт занят — следующий (до +10), иначе `error` на странице.
- Файл пропал — 404 / ошибка 70; ffmpeg нет — отдаётся оригинал.
- Плеер оборвал соединение посреди файла — тихо (так он перематывает).

## Не входит

QR-код (в программе нет его кодировщика, а новая зависимость ради него не нужна), ключи API
OpenSubsonic, запись на телефон через приложение (плееры сами скачивают), DLNA, выбор по устройствам.

## Тесты

`tests/test_subsonic.py`: вход (открытый пароль, `enc:`, токен, неверный — 40, без логина — 10);
XML и JSON одного ответа; индекс на синтетической библиотеке (исполнители, альбомы, песни, id
стабильны); каждый метод из списка; `stream` целиком и по `Range`; пережатие (пропуск без ffmpeg);
обложка; `star`/`unstar` меняют избранное; `scrobble` пишет прослушивание; `Listener` на свободном
порту отвечает на настоящий HTTP `ping`. `tests/test_gui.py`: `wifi()`/`set_wifi`/`new_wifi_password`,
`wifi.json`, запуск при старте.
